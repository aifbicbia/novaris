# Novaris V1.0 页面、公式与阅读质量检查

日期：2026-10-15。生产预览构建：`0ziFwESz-0vtieDPs4ljO`。本轮只处理显示、导航和文案，不新增题目，不公开部署。

## 实际修复

- 修复 12 条 Key ideas 在标签、原生筛选选项和激活筛选中显示美元分隔符或 TeX 命令的问题。同一字段出现在题目副标题、归档摘要时也使用可读标签。平方、角度、密度、乘法和向量含义均保留；原始字段、筛选值和 URL 不变，不进行任意数学字符串清洗。
- 修复异常筛选 URL 引用对象继承属性时的显示错误。`__proto__`、`constructor`、`toString` 等值按普通不可用选项处理，不再作为对象或函数渲染。
- 题目顶部、面包屑和试卷侧栏使用已有的完整场次名称，区分同年不同月份的 USACO 试卷。手机端新增 Statement / Answer / Solution / Sources 跳转，保留原有展开状态与题号导航。
- 精简部分过长的来源链接标题，保留非官方、第三方镜像、同一文档等资格说明。来源元数据、地址和历史证据均不改写。原项目与公开副本的来源描述有意有所不同；公开副本中已经简洁的描述继续沿用。
- 为公式、段落和代码的原生滚动区域补充一致的可见焦点样式，保留内部横向滚动，不缩小整页或裁掉公式。

## 页面整理

保留原有衬线标题、深蓝文字、暖白背景和细分隔线。首页改为直接说明资源用途，减少口号、重复 Available 徽标和未开放功能的整块推广；数学、物理、编程均提供真实内容入口。About、Programs 与页脚压缩重复说明，保留学习数据存储和来源权限等必要信息。计划页面与原有 URL 仍保留。

同一浏览器视口下，首页文档高度从桌面的 2,095px 减至 1,737px，390px 手机视口从 3,262px 减至 2,757px。这是页面布局长度对比，不是速度评分。

## 数据与交付保护

仍为 **321 套试卷、5,931 条题目记录与保留英文解析；5,924 份可读，7 份原有待审解析继续隐藏**。原项目 1,526 个冻结核心文件、公开副本全部 655 个数据文件哈希不变。旧题目 ID、公开链接、学习存储协议、已有审核记录和两个旧源码包均保留。

原项目与 `release/novaris-v1` 的本轮页面及辅助代码同步。公开交付更新 `release-integrity.json`，另存 `release/novaris-v1-display-source.zip`。域名、邮箱和隐私配置保持原有待确认状态，不购买服务或部署。

详细解答继续在服务端渲染。全部生成 JS/CSS 合计 1,026,749 字节，属于所有文件的未压缩总量，不是一次页面传输量。每套试卷各取一段真实长解题步骤检查，321 个样本均未作为原文或 JSON 转义文本进入客户端 JS；这是一项抽样边界检查。

## 范围与后续

本轮验证格式、编码、实际阅读和交互，没有重新认证全库数学证明。已测浏览器为本机隔离 Chrome；物理设备、其他浏览器与真实网络仍可在选定托管服务后复验。长公式和代码保留内部横向滚动，图片保留原有全尺寸查看入口。

未改动的旧数学规范化器在某些合成的字面 TeX 代码、占位字符串和混合转义美元数学写法中仍有限制；当前冻结内容未发现这些触发情况。未来恢复内容创作前，应单独处理这些解析器用例并重跑代码原文及货币回归，避免用通用替换猜测修复数学。

无需为本轮显示修复确定新服务。正式上线前的域名、联系邮箱、运营联系名称、托管/收件服务及真实隐私配置，仍按[发布配置指南](../launch-configuration.md)确认。
