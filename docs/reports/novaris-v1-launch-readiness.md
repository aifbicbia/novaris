## 4. 网站功能、文案与视觉整理

当前可用：Home、Problem Archive、题目详情、Programs、About、Contact、Source Policy、My Learning、Study guide、Privacy，以及 404 和错误恢复页面。搜索支持竞赛、年份、试卷、主题、难度及排序；按真实赛次分页与题号导航。URL 保存筛选与页码，详情返回整卷、浏览器返回保持上下文。

Saved / Bookmarks、Review Later、Completed 三个标记相互独立，使用当前浏览器存储；刷新和跨标签页同步可用。没有账户、跨设备同步、支付、预约或真实论坛。Tutors、Discussion、Study notes 的旧 URL 保留为 **Coming Soon**，从主要导航撤下，不展示模拟成员、帖子、课程或预约效果。

主要修复和保护措施：

- 试卷定位以正式赛次关联为准，所有 5,931 个 slug 查找与整卷链接检查通过；历史不同题量、轮次保持原结构。
- 首页、About、Archive 和 Programs 使用正式数据统计，并区分记录、可读原题和可用解析；首页的 21 collections 与 14 合并栏目口径明确。
- 未经许可的原题内容不进入公开搜索索引；争议解析的详情、预览及 SEO 描述都使用谨慎状态。
- 学习状态继续沿用原 ID 和存储协议，异常存储会显示可用的临时状态，不伪造完成进度。
- 手机公式和 C++ 代码在自身容器滚动，整页保持宽度；选择题选项、图片署名和来源入口清晰。
- Contact 不再使用未确认的邮箱或收件表单，联系地址仅从负责人配置读取。

保留原有蓝白、暖金、衬线标题及 Editorial 布局，统一正文间距、卡片、按钮与来源提示，未替换通用模板。公开介绍采用简洁具体的学习功能和范围说明；没有增加机构合作、法律身份、用户量、获奖或专业认证声明。复杂证明及参考程序保持必要的完整论证，未批量改写正确解析。

## 6. SEO、安全、隐私与交付隔离

页面标题、描述、图标、1200×630 Open Graph 图片、站点地图、robots、canonical、404 和错误恢复已配置。正式域名尚未确认：当前预览为 noindex、robots 禁止索引、sitemap 为空，不编造公共 canonical。配置经过 HTTPS、凭据、路径、查询、片段及无效邮箱的隔离测试。

因此构建仍有两条 metadataBase 使用本机默认地址的提示。负责人确认 `NOVARIS_SITE_URL` 并重新构建后，才能验收真实公共 canonical、分享图片绝对地址、robots 与 sitemap。My Learning 保持 noindex。

响应配置包括 nosniff、限制跨站 referrer、禁止嵌入 iframe，以及禁止相机、麦克风和位置权限；移除框架标识响应头。公开项目与构建输出的检索没有发现匹配的密钥、私有依赖或内部审核材料。此范围检查不构成安全保证。

独立发布项目升级为 **Next.js 16.4.0、KaTeX 0.19.0**，并更新兼容的间接依赖，原工作区的 package / lock / 既有运行依赖保留。升级后的 `npm audit --omit=dev` **报告 0 项公告**。全依赖审核仍报告 **5 个 high 条目，来自同一个未修复的开发 glob 依赖链**：braces → micromatch → fast-glob → Next lint 插件及配置。公告影响 braces ≤3.0.3，目前列为没有补丁版本；它不在本次生产依赖列表中，但仍须跟踪，开发和构建只应使用可信工程输入。没有通过回退 ESLint 或跳过失败来掩盖它。[braces 安全公告](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)

Privacy 说明真实的浏览器存储、搜索 URL、外部来源链接及邮件服务；当前无注册、消息提交、支付或广告跟踪。托管服务的日志、运营者联系方式和隐私处理细节尚未确定，部署前需完善，不能把应用层现状当作未来托管保证。

交付项目为 `release/novaris-v1`，源码包为 `release/novaris-v1-source.zip`，文件清单与哈希为 `release-integrity.json`。仅包括活跃代码、正式公开数据、解析、必要资源、配置、验证脚本、README 和本报告。安装依赖、`.next`、环境值、原始下载、历史快照、未发布草稿及私有报告不在源码包内；第三方依赖安装后的许可证必须继续保留。
