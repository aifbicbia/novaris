# Novaris V1.0 第1项：域名、联系、隐私与 SEO

日期：2026-10-15。本项仅处理发布配置和相关页面，不增加题目、不扩展其他功能，不注册、购买、发送邮件或公开部署。

## 实际改动

- 原项目与 `release/novaris-v1` 同步域名、邮箱、隐私和 SEO 代码，保留原有页面风格及公开题目 URL。
- 新增明确的索引开关。域名、邮箱和隐私必需信息完整有效，负责人确认隐私说明且主动开启索引后，才允许公开索引。缺省值保持空或 `false`，预览使用 noindex、禁止抓取和空 sitemap；仅填入域名不会开放索引。
- 统一生成安全邮件链接：地址中特殊字符单独编码，纠错主题的换行归一化，正文采用标准换行。修复模块初始化时捕获邮箱、导致联系栏目与当前配置不一致的问题；联系方式仅从负责人提供的有效地址读取。
- Privacy 增加可配置的公开联系名称、托管服务、收件邮件服务、访问日志和询问邮件保留说明、政策日期。明确学习列表的存储键、删除方式、不同来源的存储隔离、查询 URL 及外链请求；未知信息保持待确认，不编造运营者、服务或法律身份。
- canonical 路径拒绝查询、片段、空白和控制字符，解析后再验证同源。已确认域名用于 canonical、Open Graph 和 Twitter；无域名时不产生 localhost 或虚构的分享地址。
- `/opengraph-image` 保留原 URL 和 1200×630 品牌图片，改为显式静态路由，解决未知域名时文件约定自动补 localhost 分享元数据的问题。最终构建不再出现 metadataBase 警告。
- 首页显式使用带 Novaris 品牌的标题，修复同层标题模板不生效造成的缺漏。My Learning、计划页面和七个暂缓解析页保持 noindex，不加入 sitemap。公开 robots 允许抓取 noindex 页面，以便读取该指令。
- 新增 `check:launch`、`validate:launch` 和带前置检查的 `build:public`。未配置时普通预览检查正常通过，公开构建检查明确阻止继续；这些命令不发送、购买或部署。

完整字段和操作方法见[发布配置指南](../launch-configuration.md)与项目 `.env.example`。配置必须在构建前设置，更改后重新构建，不能仅更改启动时环境。
