# Novaris V1.0 交互与格式保护复查

日期：2026-10-15。当前生产预览构建：`_Rjby6gKawKl9BWr6b9Tb`。本轮继续在原项目工作，不增加题目、不部署。

## 实际修复

### 快速搜索漏字

原版本在连续输入时，由滞后的 URL 渲染覆盖输入框文字。真实浏览器复现：题库搜索 `mirrors` 可能只剩 `mrs`，My Learning 搜索 `geometry` 可能只剩 `oy`；10ms 字间隔也出现漏字。

两个搜索框现在即时保存输入值，仅在 URL 快照与浏览器当前位置一致时同步外部导航状态。清空搜索、移除搜索标签和重置筛选同样更新输入值，保留现有 URL、筛选与返回逻辑。最终浏览器在两个输入框分别测试 0/10/30/80ms 四档速度，**8/8 完整保留输入**；全选替换、多词及大小写、清空、Back/Forward 也完成复查。

### 学习按钮遵循可见意图

旧按钮先按屏幕状态报告“加入”，再根据最新存储值反转；如果另一标签页已改变同一标记，而事件尚未送达，就可能执行相反操作。按钮现在调用已有的显式设置接口，执行当前显示的保存或移除意图，保留其余标记和题目。

针对 Saved / Review Later / Completed 各自的加入和移除，共六组真实组件回调检查通过；原有存储结构、键名及 store.toggle 接口不变。学习回归从 15 项增加到 **21 项**。

### 代码、数学与链接的边界

旧转换器可能把代码里的字面 TeX 分隔符改成数学，或者让美元占位文字进入公式。现通过已有 CommonMark 解析器的位置保护代码、链接目标和引用定义；链接标签仍可显示数学。字面代码在 Markdown 解析前恢复，使用回调避免 `$$`、`$&` 等被当作字符串替换指令。

转义美元使用每字段不冲突的标记，并在 KaTeX 运行前按数学/正文上下文恢复。另保护双美元边界、字面反斜杠，以及跨越代码的旧格式括号转换。新增 **`npm run validate:markdown`，24 项回归通过**，覆盖行内/围栏/缩进/嵌套代码、金额、数学、链接、引用、选项和字面标记。

显式声明已安装并锁定的 `mdast-util-from-markdown@2.0.3`。两个项目的 **536 个非根包锁文件记录均未改变**；仅在根依赖声明中提升已有依赖，没有下载新包或升级框架。

## 浏览器交互范围

使用隔离的本机 Chrome，检查题库与 My Learning 搜索、组合筛选、分页和 URL 归一化、返回题目来源列表、Back/Forward、手机菜单的 Tab/Shift+Tab/Escape/遮罩、滚动与焦点恢复。原生解析展开、片段跳转、关闭脚本及延迟加载脚本期间先展开后恢复也经过检查。

学习功能涵盖跨标签页更新、外部清除、26 条变成 25 条时的页码与焦点、标记独立性，以及模拟存储拒绝、配额失败后恢复、损坏数据和未来版本保护。故障条件仅注入隔离测试环境，未操作实际用户学习列表；没有声称模拟条件等同于真实磁盘故障。

最终主浏览器过程的页面、资源、控制台及意外外部请求错误均为 0。原脚本两个即时断言及对应阶段记录没有被改写为成功：复合筛选前进后退另测多个时点均一致；菜单原生关闭后，ARIA 和滚动锁在下一帧约 13ms 恢复一致。补充五项检查通过，没有发现稳定复现的剩余故障。原即时组合断言缺少单字段快照，不据此编造具体失败原因。主过程在即时断言后未到达的菜单断点变化及菜单链接分支，不计为本轮通过项目；菜单组件本轮未改动。

实际查看两张最终手机交互截图，搜索、筛选标签、学习列表和按钮均可读。上一轮 118 次布局视图与 35 张题图的手机端记录继续保留，本轮没有把它们重复描述成新执行结果。
